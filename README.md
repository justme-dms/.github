# .github

Organization-level defaults for **JustMe Digital Marketing Services**.

This repository contains no application code. GitHub reads certain files from a
repository named `.github` and applies them across the whole organization:

| File | Effect |
|---|---|
| `profile/README.md` | Renders as the organization's public landing page at [github.com/justme-dms](https://github.com/justme-dms) |
| `SECURITY.md` | Becomes the default security policy for every repository in the org that lacks its own |
| `CODEOWNERS` | Default pull-request reviewers for repositories that do not define their own |

Editing `profile/README.md` changes what the world sees on the organization page,
so treat it as published copy rather than internal notes.

**Nothing in this repository may contain client names, credentials, infrastructure
identifiers, internal hostnames, or staff names.** It is public. The platform
repositories are private commercial software and stay that way.
